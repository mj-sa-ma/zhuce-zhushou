# 注册助手

一个面向中文用户的单页本地工具，打开 `index.html` 就能使用。项目不依赖后端服务，适合用来临时生成和整理注册资料。

## 功能

- 英文姓名生成
- 邮箱前缀与常见邮箱入口整理
- 随机密码生成
- 批量生成资料
- 浏览器本地账号记录与导出
- 示例账单信息复制

## 使用方式

直接用浏览器打开 `index.html`。

所有记录默认保存在当前浏览器的 `localStorage` 中，不会上传到服务器。换浏览器、清理浏览器数据或无痕模式关闭后，本地记录可能丢失。
